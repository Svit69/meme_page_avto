# Картинки для галереи

В этой папке подключены пять файлов:

- `horizontal.png` — горизонтальная картинка (уже добавлена).
- `vertical-1.png` — вертикальная картинка (уже добавлена).
- `horizontal-2.png` — вторая горизонтальная картинка (уже добавлена).
- `vertical-2.png` — вторая вертикальная картинка.
- `vertical-3.png` — третья вертикальная картинка.

Все картинки подключены в формате PNG. При смене формата измените
расширение соответствующего пути в `src/data/memes.js`.
Размеры могут быть любыми: сайт использует реальные пропорции файла.
Изображения показываются целиком, без обрезки.
Пока картинки не добавлены, отображаются заглушки с уведомлением.
После добавления закоммитьте и отправьте файлы в GitHub.
Если Vercel подключён к репозиторию, он автоматически обновит сайт.
