# Мемотека

Галерея трёх мемов на чистом JavaScript, HTML и CSS, без runtime-зависимостей.
Главная страница: `/`. Отдельные страницы: `/memes/horizontal`,
`/memes/vertical-1`, `/memes/horizontal-2`.

## Картинки

Папка: `public/memes/`. Подробности — в её `README.md`.
Первые две картинки подключены как `horizontal.png` и `vertical-1.png`.
Вторая горизонтальная картинка подключена как `horizontal-2.png`.
Названия, подписи и пути изменяются в `src/data/memes.js`.
Без файла показывается заглушка. Изображения всегда помещаются целиком.
Горизонтальный мем автоматически поворачивается на портретном экране,
если поворот увеличивает видимый размер. Кнопка поворота доступна для всех мемов.
Кнопка полного экрана работает в браузерах с поддержкой Fullscreen API.

## Локальный запуск

Требуется Node.js 22 или новее. Установка зависимостей не нужна.

```sh
npm run dev
npm test
npm run build
npm run preview
```

Адрес: `http://127.0.0.1:5173`. Результат сборки: `dist/`.

## Vercel

Импортируйте `Svit69/meme_page_avto` в Vercel и выберите preset `Other`.
Build Command: `npm run build`. Output Directory: `dist`.
Конфигурация уже задана в `vercel.json`. Страницы генерируются отдельно,
поэтому прямые ссылки и перезагрузка работают без SPA-rewrite.
После подключения GitHub изменения в `main` автоматически запускают деплой.

## Архитектура

- Абстракция: `Meme` задаёт контракт модели и `shouldRotate()`.
- Инкапсуляция: приватные поля `#definition`, `#memes`, `#rotation`.
- Наследование: `LandscapeMeme` и `PortraitMeme` расширяют `Meme`.
- Полиморфизм: просмотрщик вызывает `shouldRotate()` нужного типа модели.

Исходные файлы разделены по задачам, каждый содержит не более 50 строк.
Текст хранится в UTF-8. Статическому сайту ключи не нужны.
Приватные ключи храните в игнорируемом `.env` или Environment Variables Vercel;
не включайте их в клиентский код.
